    \item Cấu hình Docker containers và multi-stage builds cho các services
    \item Thiết lập và quản lý ECS clusters cho application và database services
    \item Cấu hình Application Load Balancer (ALB) và Network Load Balancer (NLB)
    \item Quản lý AWS Secrets Manager cho database credentials và session keys
    \item Cấu hình CloudWatch Logs cho centralized logging

    \item Thiết lập IAM roles và policies cho ECS tasks
    \item Tối ưu hóa chi phí và hiệu năng của cloud infrastructure

    \item Đảm bảo high availability và auto-scaling cho các services
\end{itemize}
